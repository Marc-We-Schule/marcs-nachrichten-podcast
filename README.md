# Marcs Nachrichten (Podcast)

Tägliche Nachrichten als Hörfassung mit Kapiteln, erzeugt von Claude (entwickelt von Anthropic) mit einer Computerstimme.

- Feed für die Podcast-App: https://raw.githubusercontent.com/Marc-We-Schule/marcs-nachrichten-podcast/main/feed.xml
- Apple Podcasts: Mediathek → „…“ → „Sendung per URL folgen“ → Feed-Adresse einfügen.
- Folgen älter als 30 Tage werden entfernt.
- Quelle der Texte: Nachrichten-Archiv im (privaten) Repo Claude-skills, Branch `nachrichten-archiv`.
